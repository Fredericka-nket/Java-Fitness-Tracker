# Java Fitness Tracker 🏃

## About the Project
The Fitness Tracker is an individual Java console application developed to record and summarise fitness activities.

The application allows users to track their activity, calculate steps from distance and monitor their progress towards a step goal.

## Technologies Used
- Java
- Object-Oriented Programming
- Console-based user interaction

## Features
- Records fitness activities.
- Converts distance into estimated steps.
- Allows users to set a step goal.
- Maintains a timestamped activity log.
- Provides a summary of activity sessions.
- Includes input validation.
